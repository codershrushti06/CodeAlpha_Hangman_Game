# CodeAlpha Hangman Game

## Task 1: Hangman Game

This project is a simple text-based Hangman game developed using Python.

## Features

- Uses 5 predefined words
- Randomly selects a word
- Player guesses one letter at a time
- Maximum 6 incorrect guesses are allowed
- Displays the current progress of the word
- Detects repeated guesses
- Displays winning and game-over messages

## Technologies Used

- Python
- Random module
- Lists
- Strings
- While loop
- If-else statements

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code or Terminal.
3. Run the following command:

```bash
python hangman.py
